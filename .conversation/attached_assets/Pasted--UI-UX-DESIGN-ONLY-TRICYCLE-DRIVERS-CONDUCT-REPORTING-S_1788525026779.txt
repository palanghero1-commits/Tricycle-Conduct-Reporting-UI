# UI/UX DESIGN ONLY — TRICYCLE DRIVERS CONDUCT REPORTING SYSTEM

Design a complete, modern, polished **UI/UX prototype only** for a **Web and Mobile-Based Tricycle Drivers Conduct Reporting System with Progressive Web Application (PWA)** for the **Tricycle Operators and Drivers Association (TODA) of Barangay Old Sagay, Sagay City, Negros Occidental**, primarily serving **State University of Northern Negros (SUNN) students**.

## CRITICAL INSTRUCTION — UI/UX ONLY

This project is STRICTLY for **UI/UX design and frontend visual prototyping**.

DO NOT build or implement:

* Backend
* Database
* Supabase integration
* API calls
* Authentication logic
* Real user registration
* Real login functionality
* Real file storage
* Real notification services
* Real email/SMS services
* Server-side logic
* Business logic
* Real-time functionality
* Payment systems
* External integrations

Use **static mock data and frontend-only interactions** to demonstrate the interface.

The goal is to create a visually complete and highly polished prototype that demonstrates how the final system should look and feel.

Do not spend effort explaining or implementing backend architecture. Focus entirely on:
**visual design + user experience + layout + navigation structure + responsive behavior + component design + interactive UI states.**

---

# 1. DESIGN GOAL

Create a professional civic/public-service UI that feels:

* Modern
* Clean
* Trustworthy
* Safe
* Simple
* Accessible
* Student-friendly
* Professional
* Organized
* Mobile-first
* Appropriate for a university/community system

The interface should look like a real production application, but all information can be mock/demo data.

The system should NOT look like:

* A police/military application
* A social media application
* A ride-booking application
* An e-commerce application
* A generic corporate dashboard

It should feel like a **student-centered community complaint/reporting platform**.
